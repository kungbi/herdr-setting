# Personal Herdr Settings

My personal Herdr setup, including a Dracula theme, custom keybindings, and the plugins I use.

- `herdr/config.toml` — theme, UI preferences, and keybindings.
- `herdr/plugins.txt` — external plugins and pinned refs.
- [herdr-agent-picker](https://github.com/kungbi/herdr-agent-picker) — a keyboard-driven agent picker.

This is a personal configuration backup, not a general-purpose setup guide. Adjust it to your own environment before using it.

Credentials, local environment files, and running sessions are not included or synced.
